## 2. 待裁定事项（需本人拍板）

### 2.1 复牌日跨期收益如何处理

| 项目 | 内容 |
|---|---|
| 涉及观测 | 顺丰控股 2021-02-10；中信证券 2022-01-27（中信当日同时叠加配股除权） |
| 问题 | 这两日的"日收益"实为跨越停牌期的累计价格变化，当作单日收益会夸大当日波动与相关性 |
| 方案 A（推荐） | 主结果中将这两日收益置为缺失，不进入描述统计、波动率与相关性；在异常收益检查中单独列出，并做一次保留该观测的敏感性比较 |
| 方案 B | 保留为观测，但单独标记为"跨期收益"，并在全文说明 |
| 方案 C | 按停牌天数摊薄为等效日收益（等于假设收益均匀实现，属额外假设，不推荐） |
| 影响 | 影响 2 个观测，占正式样本 13,831 的 0.014%；对组合净值曲线影响需评估 |

### 2.2 组合收益在个股停牌日如何处理

| 项目 | 内容 |
|---|---|
| 场景 | 2021-02-05/08/09 顺丰无行情；2022-01-19—01-26 中信无行情 |
| 方案 A（推荐） | 缺失日将该股从当日组合中剔除，权重在其余股票间重新归一化，组合收益照常计算 |
| 方案 B | 该股当日收益按 0 计入（等于假设停牌日无收益，属额外假设） |
| 方案 C | 该日组合收益整体缺失（会打断净值曲线与年化计算，不推荐） |
| 说明要求 | 必须说明处理方式、受影响日数，并核验每日权重和为 1 |

### 2.3 20 日滚动年化波动率的窗口口径

| 项目 | 内容 |
|---|---|
| 问题 | 顺丰、中信在停牌前后窗口内实际观测不足或跨越缺口，窗口按"该股票自身连续 20 个观测日"还是"共同日历 20 个交易日" |
| 推荐 | 按该股票自身连续 20 个收益率观测；若窗口内跨越停牌缺口则该窗口不计算，并在图注说明 |
| 依据 | 题目：滚动窗口包含 20 个交易日，不足完整窗口时不计算 |

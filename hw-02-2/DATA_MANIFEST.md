## 3. 关键筛选条件（导出时设定）

| 表 | 筛选条件 |
|---|---|
| 资产负债表 / 利润表 | 报表类型=合并报表（导出时含 A/B，代码内筛 `Typrep=A`）；会计期间 2005-01-01~2015-12-31（2004 单独导出）；代码=本研究 170 家清单 |
| 股权性质 | 代码=170 家清单；截止日期 2004-12-31~2015-12-31 |
| 年度表 | 全部代码（非代码池，以便逐年判定行业与对账）；统计截止日期 2004-12-31~2015-12-31 |

## 4. 单位与口径

| 项 | 说明 |
|---|---|
| 金额单位 | **元**（人民币）。核验：万科 2015 年末资产总计 611,295,567,689 元，与公开年报一致 |
| 会计期间 | `Accper` 为统计截止日期；仅取 `12-31` 年末记录（季报、1 月 1 日期初记录保留在原始文件中，不进入年度面板） |
| 报表口径 | 合并报表（`Typrep=A`）；净利润用合并口径，不混用归母 |
| 行业口径 | ≤2011 年用证监会 2001 版（J\*=房地产业）；≥2012 年用证监会 2012 版（K70=房地产业） |
| 产权口径 | 按**当年**实际控制人性质；国企→国有、纯民营→民营、外资/其他/复合→其他、缺失→不明 |

> **受限数据声明**：以下 CSMAR 数据属授权数据库内容，源文件标注「仅供中山大学使用」，
> **不上传公开仓库或公开网盘**（作业第 5 节）。本目录整体已加入 `.gitignore`。
> 仓库提供**完整下载条件、字段清单与代码**，在授权范围内可自行复现。

## 3. 可公开的输出（已入库）

`../outputs/`：4 张图（逐年公司数与产权结构、六指标均值中位数、国有 vs 民营均值/中位数）与 4 张汇总表（有效样本量、产权结构、样本流、敏感性）。均为**汇总结果，不构成原始记录再分发**。

## 4. 复现步骤（相对路径）

1. 按 `../DATA_MANIFEST.md` 的下载条件，本人从 CSMAR 导出上述 5 张表，放入上面指定的相对路径；
2. 进入 `hw02-2/`，运行 `python code/build_panel.py`（生成面板与样本处理表）；
3. 运行 `python code/make_outputs.py`（生成四类图与汇总表）；
4. 依赖见 `../requirements.txt`；字段对应表见 `../field_mapping.csv`。

若无法获得 CSMAR 授权，可只运行第 3 步读取仓库内已有的汇总输出；企业层面的面板与指标无法在无授权情况下重建。

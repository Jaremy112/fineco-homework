## 0. 先回答"为什么在 data.csmar.com 上找不到这个数据集"

**因为 CSMAR 没有现成的"2005—2015 房地产数据集"。** 它是一个查询平台，不是数据集列表：
登录 → 选数据库系列 → 选表 → 勾选字段 → 设筛选条件（年份/市场/行业）→ 导出 Excel/CSV。
"2005—2015 房地产 A 股年度数据"是要你按下面的路径**自己组合查询条件导出来的**。

课件中 CSMAR 相关链接共三个：

| 链接 | 出处 | 对本题的作用 |
|---|---|---|
| https://data.csmar.com/ | 第 2 讲数据清单 | **本题下载入口**（需学校订阅权限登录） |
| https://www.csmar.com/channels/31.html | 第 1 讲产品说明 | 仅产品介绍，无数据 |
| 坚果云 CSMAR 2014–2025 数据包 | 第 5 讲 DATA_ACCESS.md | **不适用于本题**：只覆盖 2014–2025，是课堂案例数据 |

**登录方式**：学校订阅一般走校园网 IP 自动授权；在校外用学校图书馆的 VPN / CARSI 登录后再访问 data.csmar.com。若提示无权限，先确认是否连了校园网/VPN，仍不行联系教师或图书馆。

## 1. 三条硬约束（导出前读）

1. **年份选 2004—2015**（不是 2005—2015）：ROA/ROE 的平均分母需要 2004 年末数据。
2. **报表类型选合并报表**（资产负债表/利润表导出时报表类型通常 A=合并、B=母公司），全程只用合并口径。
3. **样本不能从现在活着的公司往回挑**：导出时不要设"剔除退市公司"；行业与产权都要**逐年**数据，不能用当前值覆盖历史（作业原文明令禁止）。

## 2. 导出清单（6 项，一次导完）

站内路径以 CSMAR 数据中心实际菜单为准（不同年份界面措辞略有差异，括号内为英文库名线索）。

| # | 站内路径 | 导出内容 | 关键字段 | 筛选条件 |
|---|---|---|---|---|
| 1 | 公司研究系列 → 上市公司基本信息 → 基本信息（年度） | 公司身份与上市状态 | 证券代码、证券简称、统计截止日期、上市状态、上市日期、退市日期 | 2004—2015；A 股（**含已退市**） |
| 2 | 公司研究系列 → 行业分类 → 上市公司行业分类（年度） | **逐年**行业归属 | 证券代码、年度、行业代码、行业名称、**分类标准/版本** | 2004—2015；**证监会 2001 版与 2012 版两套都导**（2005—2015 跨年正好经历 2012 版切换，房地产在 2001 版为 J01、2012 版为 K70；作业要求说明跨年映射方式）。**先导全部行业**，不要只筛房地产（要处理行业变更） |
| 3 | 公司治理系列 → 股东 → 股权性质文件 / 实际控制人（年度） | **逐年**产权属性 | 证券代码、统计截止日期、实际控制人性质（编码+名称）、实际控制人名称、股权性质编码 | 2004—2015 |
| 4 | 公司研究系列 → 财务报表 → 资产负债表 | 总资产、总负债、流动负债、所有者权益、货币资金、长短期借款 | 证券代码、会计截止日期、报表类型、资产总计、负债合计、流动负债合计、所有者权益合计（含少数股东权益）、货币资金、短期借款、长期借款 | 报表类型=**合并报表**；2004—2015；年度（12-31） |
| 5 | 公司研究系列 → 财务报表 → 利润表 | 合并净利润 | 证券代码、会计截止日期、报表类型、净利润（含归母净利润、少数股东损益，备核对用） | 同上 |
| 6 | 财务报表附注（备用） | 银行借款明细 | 短期银行借款、长期银行借款 | 仅当第 4 项主表字段不满足 bankloan 口径时启用 |

导出格式选 **CSV 或 Excel 均可**，每次导出**务必同时下载字段说明文件**（CSMAR 导出包自带），
并记录：导出时间、数据版本、金额单位与币种。

## 3. 变量与字段对应（导出后由代码映射）

| 作业指标 | 口径 | 需要的原始字段 |
|---|---|---|
| 资产负债率 | 总负债 / 总资产 | 负债合计、资产总计 |
| bankloan | (短期银行借款+长期银行借款) / 总负债 | 短期借款、长期借款、负债合计（缺失不按零处理） |
| 短期负债占比 | 流动负债 / 总负债 | 流动负债合计、负债合计 |
| ROA | 合并净利润 / 平均总资产 | 净利润、资产总计（t 与 t−1） |
| ROE | 合并净利润 / 平均所有者权益 | 净利润、所有者权益合计（t 与 t−1，含少数股东权益，不混归母） |
| Cash_TA | 货币资金 / 总资产 | 货币资金、资产总计 |
| 产权分组 | 国有 / 民营 / 其他 / 不明 | 实际控制人性质（**逐年**，非国有≠民营） |
| 公司数 | 逐年去重 | 基本信息 + 行业分类（逐年，不因财务缺失删公司） |

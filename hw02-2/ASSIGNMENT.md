## 3.【必做】HW02-2：房地产公司财务特征

### 样本与字段

自行从 CSMAR 下载 **2005—2015 年房地产 A 股上市公司**年度数据，使用**年度合并财务报表**，按各年年末上市状态、行业及产权属性构建企业—年度**非平衡面板**。允许上市、退市、行业或产权变化。

- 不能只从目前仍上市的公司向前追溯，也不能用当前行业或产权覆盖历史年份。
- 分类标准跨年变化时说明映射方式。
- 记录下载条件、数据表、字段、单位与日期，提供原始字段和分析变量对应表。

### 数量与产权结构

逐年统计并绘图：房地产上市公司总数；国有、民营、其他及产权不明公司数量；国有与民营分别占当年房地产上市公司总数的比例。

- 按**当年实际控制人性质**制定产权分类规则，**非国有不直接等于民营**。
- 年度公司数去重计算，**不因财务指标缺失而删去公司**。
- 存在其他或不明类别时，国有与民营占比之和可以小于 100%。

### 财务指标与时序分析

| 指标 | 本次作业统一口径 |
|---|---|
| 资产负债率 | 总负债 / 总资产 |
| bankloan | (短期银行借款 + 长期银行借款) / 总负债 |
| 短期负债占比 | 流动负债 / 总负债 |
| ROA | 合并净利润 / 平均总资产 |
| ROE | 合并净利润 / 平均所有者权益 |
| Cash_TA | 货币资金 / 总资产 |

- 短期银行借款和长期银行借款**直接从 CSMAR 下载**，保留字段说明，**缺失不自动按零处理**。
- 平均总资产和平均所有者权益取上年末与本年末的平均值，**须额外下载 2004 年末相关数据**。
- 利润与权益使用一致的合并口径，不混用归母净利润与包含少数股东权益的总权益。
- 现金持有用货币资金衡量，短期负债用流动负债衡量，分别区别于现金及现金等价物、短期银行借款。
- 对零分母、负权益和极端比率，自行确定处理规则，说明经济含义和影响。

对六个指标分别呈现：

1. 全部房地产企业历年均值与中位数时序图；
2. 国有和民营企业历年均值比较图；
3. 国有和民营企业历年中位数比较图；
4. 各指标对应的年度有效样本量表。

可以用分面图组织。**平均资产负债率为企业比率的算术平均，不是行业总负债除以总资产。**

解释公司数量、产权结构及财务特征的变化，均值与中位数的差异，国有与民营的差异，以及指标突变是否由离群值、异常分母、样本进出或产权变更引起。**描述性差异不能直接解释为产权的因果作用。**

保留**样本处理表**，记录下载、筛选、合并和变量构造阶段的公司数与企业—年度观测数。检查主键、重复报表、合并关系、未匹配记录、单位、缺失和离群值，并解释主要决定。

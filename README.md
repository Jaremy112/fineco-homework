# fineco-homework

金融计量经济学（FinEco）个人作业仓库。

本仓库用于保存整个学期的研究计划、实验、作业和个人网站；与教师课件仓库 `../FinEco` 分开维护。

## 目录

- `hw-01/`：一页研究计划
- `experiments/`：从教师基准案例复制出来的个人实验；先保留基准，再一次只修改一个条件
- `data/`：仅保存允许进入个人仓库的数据或衍生数据；课程冻结数据优先通过相对路径说明来源
- `outputs/`：个人实验输出

## 使用原则

1. 教师课件在 `../FinEco` 中阅读和复现，不在其中保存唯一一份作业。
2. 作业、个人修改和实验只写入本仓库。
3. 不向教师仓库推送个人作业。
4. 不提交凭据、受限数据、缓存和虚拟环境。
